# Cache Coherence v1.0 Freeze Manifest

**Release branch:** `release/v1.0`  
**Frozen source:** the single commit that updates `cache_coherence` for this
release; `release/v1.0` points to the same commit after both GitHub Actions
jobs pass.  
**Scope:** dual-L1 MESI cache subsystem, verification, and benchmark v3. PPA
and physical SRAM/ASIC signoff are outside this freeze.

## Specification and RTL

- Primary behavior and interface specification: [`cache.md`](../cache.md).
- Design and verification plan: [`cache_spec_and_verification_plan.md`](../cache_spec_and_verification_plan.md).
- RTL implementation and hierarchy: [`../rtl/README.md`](../../rtl/README.md),
  `rtl/Coherence.files.f`, and the `rtl/common`, `rtl/l1`, `rtl/l2`,
  `rtl/directory`, `rtl/interconnect`, `rtl/bus`, `rtl/cluster`, and `rtl/top`
  source directories.
- Integration tops: `CoherentCacheSubsystem` and
  `CoherentCacheAxiSubsystem`.

## Verification plan and bug fixes

- Module and subsystem directed/random regression: `make
  COHERENCE_JOBS=2 coherence_regression`.
- Python/Toffee independent data and MESI checking, including directed
  ownership transfer, Put/eviction, reset, backpressure, seeded random traffic,
  checker-driven functional closure, and benchmark v3:
  `make COHERENCE_JOBS=2 coherence_python_verify`.
- AXI top-level burst memory model and adapter channel/ID testing:
  `make COHERENCE_JOBS=2 coherence_axi_e2e` and
  `make COHERENCE_JOBS=2 coherence_axi_python_test`.
- Component formal and bounded reachability checks:
  `make COHERENCE_JOBS=2 coherence_formal`.
- Recent bug investigations and fixes are timestamped in
  [`update_log.md`](../update_log.md). In particular, randomized concurrent
  traffic exposed a shared L2 directory lookup race; request allocation was
  interlocked with the active transfer/grant lookup and address assertions
  were added. A separate Grant valid/ready mismatch was fixed so an L1 cannot
  consume a data Grant unless the subsystem engine can own its data stream.

## Benchmark v3

- Python/Toffee JSON and CSV include 32 independently checked L2 hits, four
  memory latency settings, five fixed-seed mixed dual-core workloads, L1/L2
  hit/miss rates, latency, throughput, memory traffic, and phase samples.
- AXI top JSON and CSV include five fixed-seed end-to-end runs, request latency,
  throughput, memory bandwidth, burst counts, outstanding reads, and channel
  stall counts.
- Pre-change and final A/B artifacts are under `benchmarks/results/`; the
  measurement and result summary is
  [`coherence_benchmark_v3_results_2026-10-25.md`](../coherence_benchmark_v3_results_2026-10-25.md).
- The selected RTL change overlaps L2 line-read issue with accepted data Grant.
  The isolated L2-hit workload measures 23→22 cycles across 32 samples.

## Reproduce the frozen checks

```bash
make gen_dut && make test
make COHERENCE_JOBS=2 coherence_verify
```

GitHub Actions must show both `Legacy Cache Regression` and `coherence` green
for the commit before `release/v1.0` is created. Formal evidence is component
and bounded; it is not an unbounded proof of the entire cache subsystem.
