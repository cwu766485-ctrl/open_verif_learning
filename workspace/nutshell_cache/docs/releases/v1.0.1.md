# NutShell Cache v1.0.1 Release Candidate

**Status:** release candidate; create the `v1.0.1` tag/release only after the
full Legacy, Formal, and Coherence workflow passes on one source commit. The
frozen `release/v1.0` reference remains unchanged.

## Release contents

- MESI dual-L1/shared-L2 RTL and the clean-invalidation/refill overlap fix.
- Closure of the dense same-L2-set victim race: the original 14/20 failing
  seeds now pass 20/20 seeds × 200 operations with independent data,
  MESI/Directory, and transaction-completion checks.
- The `coherence_dense_set_stress` Make target is present and is invoked by
  `coherence_verify`; the CI Coherence job runs that target through
  `make coherence_verify`.
- Python/Toffee message-passing, false-sharing, and generation-counter tests;
  updated coverage/testplan, scoreboard, benchmark artifacts, and final reports.
