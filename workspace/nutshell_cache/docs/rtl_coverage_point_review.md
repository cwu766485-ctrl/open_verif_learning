# RTL Coverage Point Review — v1.1 Closure Candidate

This review distinguishes source-level observations from evidence collected in a particular elaborated top. A block-level hit does not change a zero count in the main-subsystem dataset. No point is waived by this document, and no Formal result is claimed unless the cited proof is explicitly run for that property.

## Dataset and baseline

The raw source is the Verilator coverage audit generated by `make coherence_coverage_audit`. Each elaborated top is recorded independently in `reports/coherence/rtl_coverage_dataset_manifest.json`; counts from distinct tops are not added. The main `CoherentCacheSubsystem_tb` dataset currently reports Line 850/998, Branch 468/556, Toggle 19,996/27,474, FSM State 30/54, and FSM Arc 7/48. Its 18-source manifest and compiled-source list reconcile. The independent AXI and block datasets are supplementary evidence only.

The audit uses Verilator 5.053 devel (`v5.052-521-g6388139f7`) and `verilator_coverage` from the same tool build. Python/Toffee and SV coverage are separate runs and are not merged.

## Additional protocol-fault evidence

The SharedLineEngine block suite includes malformed memory read/write response IDs, beat/last mismatches, unsupported transfer opcode, unexpected write response, dirty-owner response mismatch/no-data, and inconsistent invalid-victim metadata. Each selected test checks `ENGINE_ERROR` and the sticky protocol error. These tests establish block-level defensive behavior for their specific injected conditions; they do not prove every error/defensive branch in every top.

## Closure rules and remaining evidence

- `COVERED` requires a nonzero point count in the exact current dataset plus a checked evidence artifact.
- A block-level hit is not evidence that a subsystem-top point was sampled.
- No unresolved point is called unreachable based on source keywords or lack of stimulus.
- No waiver is approved by this review.
- The 24 missing main-top FSM states, 41 FSM arcs, 88 branch points, and 148 line points remain subject to per-point review. Toggle points also require signal-level review; the raw percentage alone is not a disposition.
- Consequently the release decision remains **OPEN** until the point ledger, regression records, source fingerprint, and evidence are current and every required point has an accepted disposition.
